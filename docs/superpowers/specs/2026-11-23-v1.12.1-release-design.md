## Cách tích hợp đã chọn

Theo quy trình PR của các release gần nhất:

1. Push `fix/stream-terminal-opencode-v151`, tạo PR vào `master` và merge sau khi kiểm tra PR diff/checks.
2. Tạo `release/v1.12.1` từ `master` đã merge.
3. Bump ba version fields bằng một commit `chore: bump version to 1.12.1`.
4. Push nhánh release, tạo PR vào `master` và merge.
5. Tạo/push annotated tag `v1.12.1` trên đúng merge commit của `master`.
6. Publish GitHub Release `v1.12.1` với notes và để `release.published` kích hoạt `.github/workflows/release.yml`.

Cách thay thế đã cân nhắc nhưng không chọn: merge/push trực tiếp `master` (nhanh nhưng bỏ qua PR), hoặc release ngay từ feature branch (không theo update channel/master hiện tại).

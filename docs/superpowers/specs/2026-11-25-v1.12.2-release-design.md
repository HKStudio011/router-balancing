## Mục đích

Phát hành các Chat SSE fixes từ `fix/chat-sse-event-framing`:

- Parse theo SSE event thay vì physical line, giữ multi-line tool call và dataset đúng.
- Exact `[DONE]`; `[DONE]garbage` và `[DO\nNE]` không được coi là terminal.
- Không synthetic `finish_reason:"stop"` khi upstream không gửi giá trị đó.
- Thêm LastByteGap diagnostics cho EOF thiếu terminal thật.
- Giữ raw forwarding, choices[0], retry policy, ResponsesProtocol và dataset truncation/overflow behavior.

Ngoài phạm vi: không khẳng định nguyên nhân mọi lần ngắt NVIDIA/upstream đã được xác định, không hứa OpenCode Free/upstream đang hoạt động, không thay mobile runtime-pack environment.

## Quy trình đã chọn

Theo quy trình PR của v1.12.1:

1. Push `fix/chat-sse-event-framing`, tạo PR vào `master` với summary/tests/review evidence và merge sau checks.
2. Test merge result trên local `master` sau khi pull `--ff-only`.
3. Tạo `release/v1.12.2`, bump ba version fields bằng `chore: bump version to 1.12.2`.
4. Build Windows và kiểm `FileVersion=1.12.2.0`; push release branch, tạo PR version bump và merge.
5. Tạo/push annotated tag `v1.12.2` trên đúng `origin/master` chứa cả hai PR.
6. Publish GitHub Release `v1.12.2` với notes; `release.published` kích hoạt workflow build/sign/upload.
7. Theo dõi workflow và xác minh đủ ZIP, `.sig`, `SHA256SUMS.txt` cùng latest/target/digests.

Không merge/push trực tiếp `master` để né PR, không force-push, không tạo release từ feature branch, không dùng artifact local thay workflow.

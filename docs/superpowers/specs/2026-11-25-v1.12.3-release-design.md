# Thiết kế release v1.12.3

## Mục đích

Phát hành hotfix đặt `upstreamIdleTimeoutSec` mặc định về `0` (tắt idle watchdog) và bổ sung `idle_timeout` thực tế vào diagnostic đứt stream. Giá trị đã lưu trong SQLite được giữ nguyên, không migration.

## Phạm vi hotfix

- Đổi fallback trong `AppSettingsService` và giá trị khởi tạo `SettingsDraft` từ `300` sang `0`.
- Giữ validation `0..3600` và toàn bộ stream forwarding/EOF/retry semantics.
- Ghi `idle_timeout` vào pre-content và mid-stream failure diagnostics; không thêm prompt, secret, file content hoặc raw tool arguments.
- Regression tests cho missing-key default, draft default, persisted `300`, persisted `0`, watchdog-wrapped path và EOF khi watchdog tắt.

## Không thuộc phạm vi

- Không khẳng định đã sửa EOF sau ~300 giây từ SOCKS5/upstream. Nếu log mới có `UpstreamTruncatedException` và `idle_timeout=0s`, đó là upstream trả EOF khi watchdog app đang tắt.
- Không sửa SSE framing, `[DONE]`, `finish_reason`, Responses protocol hoặc retry sau khi client đã nhận content.
- Không đưa thay đổi đang dở ngoài bảy file hotfix và tài liệu release vào branch.

## Quy trình release

1. Tạo feature PR từ `hotfix/upstream-idle-timeout-v1.12.3` vào `master`, review diff/checks rồi merge bằng merge commit.
2. Test kết quả merge trên `master`.
3. Tạo `release/v1.12.3` chỉ đổi `Version=1.12.3.0`, `ApplicationDisplayVersion=1.12.3`, `ApplicationVersion=33`; build Windows, xác minh assembly version, rồi merge qua PR thứ hai.
4. Tạo annotated tag `v1.12.3` đúng merge commit trên `origin/master`, publish GitHub Release latest.
5. Workflow `release.published` phải build/sign/upload đủ ZIP, `.sig` và `SHA256SUMS.txt`; chỉ báo hoàn tất sau khi kiểm tra run và assets.

## Kiểm chứng và giới hạn

- Full .NET suite, Windows build, Go test/vet trên cây release.
- Independent review trước feature PR và kiểm tra lại các góp ý minor.
- Không dùng artifact local thay cho signed assets từ workflow chính thức.
- Không force-push, không push trực tiếp lên `master`, không tạo release từ feature branch.

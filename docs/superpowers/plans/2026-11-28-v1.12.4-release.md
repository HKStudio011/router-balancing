# v1.12.4 Release Implementation Plan

**Goal:** Phát hành `v1.12.4` từ `master` bằng release PR, annotated tag và GitHub Release workflow với signed assets được xác minh.

**Spec:** `docs/superpowers/specs/2026-11-28-v1.12.4-release-design.md`

## Global Constraints

- Version: `1.12.4.0`, `1.12.4`, `ApplicationVersion=34`, tag `v1.12.4` latest target `master`.
- Không push trực tiếp `master`, không force-push, không tạo release từ feature branch.
- Không khẳng định upstream availability hoặc rằng HTTP stream chuẩn có thể resume sau EOF.
- Bắt buộc đủ `router-balancing-v1.12.4-win.zip`, `.zip.sig`, `SHA256SUMS.txt` từ workflow chính thức.

### Task 1: Release PR

- [ ] Test kết quả merge trên `origin/master`: full .NET, Windows build, Go test/vet.
- [ ] Bump đúng ba version fields; build và xác minh `FileVersion=1.12.4.0`.
- [ ] Commit `chore: bump version to 1.12.4`, push `release/v1.12.4`, tạo PR `chore: release v1.12.4`.
- [ ] Chờ checks rồi merge bằng merge commit.

### Task 2: Tag và publish

- [ ] Viết notes theo đúng bằng chứng: EOF grace, client-owned wait, resume/boundary fixes, tests và giới hạn.
- [ ] Xác nhận tag target chứa cả feature PR #64 và version bump, rồi tạo/push annotated tag `v1.12.4`.
- [ ] Publish GitHub Release latest bằng notes file, trigger `release.published`.

### Task 3: Xác minh

- [ ] Theo dõi đúng `Build Release` run tới success.
- [ ] Kiểm release latest/target/notes và đủ ba assets uploaded, size > 0, digest khớp `SHA256SUMS.txt`.
- [ ] Báo release URL, workflow URL, version, tests và mọi giới hạn còn lại. Giữ release branches cho audit.
